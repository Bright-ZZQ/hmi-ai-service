# 从图片复绘 HMI 流程图

交付物是在指定 HMI 编辑器中保存、可继续编辑的图纸。参考图和项目图例决定图面含义。位号、阀型、管线去向或信号含义看不清时，记录疑点，先完成可判读部分。图片复绘本身不包含接入实时点位、配置跳转或设备控制。

1. **先核对目标和参考图。** 核对用户指定的标签页、项目、图纸路径或编码、画幅和已有图元。同名图纸可能来自不同项目。按管网、设备、仪表、报警和导航分区，记录管线折点、端点、流向、三通及不连通的交叉，局部放大核对位号和阀型。
2. **用小批原生样件走通绘制和保存。** 优先复用符合原图含义的库图符，否则用基础图元组合。文字、按钮和管道使用各自的原生类型。图中有虚线、旋转文字或库按钮时，尽早校准各类代表件及其回读方式。小图可直接用界面。确需使用局部图片时，说明其范围。
3. **按图层或区域分批复绘。** 一般先管网，再设备和阀门，最后补仪表、标注和按钮。图元密集且能载入原生模型时，把坐标、样式和变体保存在可重建的本地场景文件中。每批核对代表图元、接点和目标图纸后及时保存，确认图纸写入结果。批量载入前确认是追加还是重建画布，保留范围之外的原有图元和配置。
4. **用保存后的图纸验收。** 重新打开或回读同一图纸，核对连通性、流向、位号、阀体与执行器、仪表虚线、渐变和两态按钮文字。会话中断时从最近确认的保存点核对进度。交付时说明已保存和已验收的范围，以及待保存、待验收或原图难以判读的细节。

- 在浏览器操作编辑器或批量放置时，读 [HMI 编辑器实操](references/editor-workflow.md)。
- 当前编辑器提供原生图纸导入、模型接口或原格式导出，且图元较多时，读 [原生图纸批量载入](references/native-document.md)，其中链接了生成脚本、续作方法和回归数据。
- 复绘阀门、仪表信号或金属设备时，读 [P&ID 图符与渐变校对](references/pid-symbols.md)。
