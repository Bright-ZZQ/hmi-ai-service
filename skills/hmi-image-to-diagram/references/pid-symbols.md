# P&ID 图符与渐变校对

以参考图局部放大图、项目图例和已知位号为依据。相同的阀体外形可能接不同执行器；单凭颜色或位号前缀不能确认动作方式或工艺语义。无法辨认的部位可用标注说明待核对，避免用通用阀门符号掩盖有意义的差别。

- **阀门专门盘点。** 给每个阀记录阀体轴向、执行器方向与形状、阀杆或连杆、附加信号线、颜色及位号。按组合类型复用，复制后逐个核准是否与管道同轴、执行器是否在正确侧、阀杆是否接到阀体。阀体、执行器、阀杆和中心点用原生几何图元，可组合命名为 `阀门 · 位号`。
- **按参考图区分执行器。** 海水管网案例中，同一类银色阀体有沿竖管布置、执行器在左侧的，也有沿横管布置、半圆执行器在顶部的。消防水 PCV 的侧部折线、甲板支路阀的紫色阀体及不同描边、过滤器排放阀侧部的小方块都要保留。这是本例观察到的图形差异，换图时重新看图例和局部。
- **区分三通与跨线。** 管线数据表中标明每个交点是否相连。三通或同路相接的管段共用接点坐标。参考图用断口表示跨越时，在经过的管路上保留断口，并在放大图里检查是否误画成接通。
- **单独处理仪表信号。** 对照参考图确认线型、颜色、起止点和穿越关系。海水管网的绿色 PV 连线和总流程图的紫色仪表连线都用了虚线，各自独立于工艺管道。检查虚线没有被默认实线覆盖，并在整图和局部放大下确认起止点可辨。
- **先判定渐变轴，再选样式。** 沿罐体同一横截面对比两边与中心，沿另一个方向抽查是否一致。F-4002A/B 原图为横向对称高光，中心亮、左右收暗；侧装半圆执行器的对称轴则随安装方向变化。优先用编辑器支持的原生渐变。界面只有线性渐变时，将轮廓沿高光轴拆成两半，分别用相反方向的线性渐变，让亮端相接。相接边关闭描边，外轮廓如需描边可单独保留，避免中线出现深色接缝。把两半组合，位号用独立的原生文字。
- **用目测或取样验收。** 在无文字遮挡的截面对比左、中、右亮度，或者对竖向高光比较上、中、下；同时看外轮廓、接缝、法兰与管口是否闭合。左右镜像后若亮端出现在外侧，交换两半的渐变方向。按钮和单位、阀门位号、流向箭头也用原图逐项复核。
