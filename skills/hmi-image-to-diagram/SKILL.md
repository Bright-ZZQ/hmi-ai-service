# 从图片复绘 HMI 流程图

交付物是在指定 HMI 编辑器中保存、可继续编辑的图纸。参考图和项目图例决定图面含义。位号、阀型、管线去向或信号含义看不清时，记录疑点，先完成可判读部分。图片复绘本身不包含接入实时点位、配置跳转或设备控制。

1. **先核对目标和参考图。** 核对用户指定的标签页、项目、图纸路径或编码、画幅和已有图元。同名图纸可能来自不同项目。按管网、设备、仪表、报警和导航分区，记录管线折点、端点、流向、三通及不连通的交叉，局部放大核对位号和阀型。
2. **用小批原生样件走通绘制和保存。** 优先复用符合原图含义的库图符，否则用基础图元组合。文字、按钮和管道使用各自的原生类型。小图可直接在界面操作。重复图元密集时，优先把坐标、样式和变体整理成表，并在当前编辑器确有可用的原生批量接口时成批放置。确需使用局部图片时，说明其范围。
3. **按图层或区域分批复绘。** 一般先管网，再设备和阀门，最后补仪表、标注和按钮。每完成一批就核对代表图元、易错接点和当前图纸，再保存并确认成功。批量载入前先判断该操作会追加还是重建画布，保留本次范围之外的原有图元和配置。
4. **用保存后的图纸验收。** 核对管路连通性、流向、位号、阀体与执行器、仪表虚线、渐变方向和按钮文字。确认最终保存成功后，重新打开或回读同一图纸，用图元列表或属性核对关键原生对象。区分已确认保存的成果与仍有歧义的细节。

- 在浏览器操作编辑器或批量放置时，读 [HMI 编辑器实操](references/editor-workflow.md)。
- 当前编辑器提供原生图纸导入、模型接口或原格式导出，且图元较多时，读 [原生图纸批量载入](references/native-document.md)，其中链接了可复用生成脚本与本次总流程图验证数据。
- 复绘阀门、仪表信号或金属设备时，读 [P&ID 图符与渐变校对](references/pid-symbols.md)。
