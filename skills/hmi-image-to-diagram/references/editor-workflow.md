# HMI 编辑器实操

以下界面名称和行为来自海水管网、总流程图及 3# 产线案例。用当前截图、工具提示或可访问控件确认目标和操作入口。独立编辑器和项目管理页内嵌的编辑器可能显示同名图纸，写入前核对项目和资源路径或编码。

## 校准与成批绘图

- 以参考图左上角为坐标原点，从原图记录端点、拐点和图元边框。确认画布有效区域的左上和右下角，用画布内部第二个特征点验证换算。若图纸与参考图按比例对齐，可用 `屏幕X = 左 + (参考X / 参考宽) × 可见图纸宽`，Y 同理。不要把浏览器视口、灰色画布外围或标尺算入图纸宽高。缩放、平移、面板伸缩后重新校准；画布被裁切时用标尺或两个可辨认的锚点换算。
- 用同一套参考图坐标记录重复图元。管段表记录顶点、线型、流向和接点。设备表记录组合模板、锚点和朝向。文字和按钮表记录内容、边框及变体。先试画代表件，再按画面分区或样式成批操作。若能直接写入原生图纸坐标，可省去屏幕换算，但仍需核对画幅和坐标原点。
- 用原生管道描参考图的折点，别用长条填充矩形拼管网。沿主干先放置端点、支接点，再补支路。箭头和管端符号的方向应与原图一致。仪表信号一般适合作为独立的管道或线条，单独设置颜色和虚线样式。若该管道工具默认为双层描边或启用虚线，确认实际显示再批量复制。

## 样件、复制和编辑

| 操作 | 实测注意点 |
| --- | --- |
| 设属性 | 用图元列表或画布选中对象，先读 `图元类型`、名称或宽高。不同属性组会出现同名的渐变和描边字段，按组定位。本次编辑器里的通用填值有时只改了输入框；实际聚焦、全选、输入、按 Enter，切换选中对象再回来读取属性，可确认提交。 |
| 画点选多边形 | 首件确认单击、双击的开绘与收笔方式。小轮廓收笔时曾同时出现一个完整对象和一个约 1×1 的图元。以预期的宽高和图元列表确认选中的是完整形状，再上色或组合。列表刚更新时重新观察一次，只移除已确认由本次操作生成的多余图元。 |
| 复用同型设备 | 先用位号或用途命名组合，再以组合复制。案例中的画布菜单有 `拷贝` 和 `粘贴`，比依赖浏览器剪贴板快捷键更可靠。粘贴锚点曾跟随点击菜单项的位置。先试一件并用可见菜单范围确认落点；可行时在预定落点打开覆盖该点的菜单再点击。移动小组合时从形状内部拖动，避开边框和缩放手柄，放置后立即核对位置与宽高。出现宽高突变时撤销该次变形并重新定位。 |
| 查找对象 | 图元列表可能按滚动范围渲染。找不到已知对象时，用列表的名称搜索来定位；清除筛选后再跨行多选并组合。替换旧对象前核对名称、类型、内容或尺寸，保证选中的是本次需要替换的条目。 |
| 设按钮与文字 | 同时填写按钮的 `抬起显示文本` 和 `按下显示文本`。先试最窄的开阀、关阀按钮及每排最长的导航文字，在整图和局部放大下确认没有裁字。总流程图案例中，按控件缩放比例反算字号会裁掉最后一字，直接填写字号后才完整显示。核对两态属性即可，读数用原生文本配独立底框，状态灯与按钮分别建图元。 |

## 保存与回读

- 试画首批之后就保存。每批检查代表件、跨区接点和末件是否出现在正确图纸上，再保存。编辑器可能分别保存图纸和缩略图，缩略图刷新或未保存标记消失只能作为提示。优先核对图纸保存回执。界面没有明确回执时，用编辑器回读核对。
- 最终保存确认后，重新打开或重新载入同一图纸。核对画幅、代表对象和可获得的图元数量，并从列表或属性抽查管道、组合子件、读数和原生按钮。整图截图用来核对布局，局部放大用来核对接点和小字。
- 操作异常时先读列表、属性和保存状态，区分未提交、落点偏移、重复图元、异步载入和保存失败。恢复后检查在途批次是否已经落盘，再决定是否重试。

## 会话中断后续作

- 连接失效后优先重新绑定用户指定的标签页。需要重开时，通过同一项目的正常入口进入。3# 产线案例中，新标签页直接打开通用编辑器地址只显示空白页，平台的项目管理界面也未显示原项目的图纸。原网址相同、登录账号相同或能打开项目管理页，都不足以确认已恢复目标。
- 重新取得编辑权限后，先核对项目、资源路径和图纸编码，再从持久化图纸比对最近已确认批次的图元数和代表件。目标或保存结果仍无法确认，或者工具明确要求停止时，结束当前操作并报告最后确认的批次，以及尚未保存、未回读或有歧义的部分。
